# 设置信息架构重组

## 背景

见 `research/ui-inventory.md`：设置窗口 10 个平级分区无分组逻辑；「关于」装着登录启动与自动更新；「概览」是杂物抽屉（弹窗页签排序、采样参数等互不相关的五件事）；「仪表盘」排第一却 0 个设置项且非默认页；pmset 系统级开关只在弹窗里；电源监控被 onAppear 隐式永久开启且无关闭开关；设置页点快捷操作磁贴会直接执行（含清空废纸篓）。目标形态见 `design/menucue-redesign.pen` 画板 A（IA 映射）、B（侧边栏+触控板）、D（操作中心）、E（弹窗操作页）。

## 目标

设置窗口收敛为 3 组 9 项，每个设置只有一个权威归属；弹窗「操作」页重组为可检索、分组、渐进披露的结构；消除隐式开启与误触执行两类footgun。

## Requirements

### R1. 侧边栏 3 组 9 项（分组标题 + 分区）

| 组 | 分区 | 内容来源 |
|---|---|---|
| 界面 | 菜单栏 | 菜单栏格式、时钟轮播（原「日期与时间」前半）、概览显示时区、macOS 系统时区 |
| 界面 | 面板 | 弹出面板页签排序（原概览）、采样参数（原概览）、动画效果（原外观第二组） |
| 界面 | 日历 | 日历与日程（原「日期与时间」后半）、日历权限状态与引导 |
| 界面 | 操作中心 | 原「快捷操作」重构（见 R3） |
| 输入 | 触控板 | 现触摸板分区平移（内部结构微调见 R5） |
| 输入 | 提醒规则 | 原「通知」更名（设备标识/渠道/告警规则不动） |
| 系统 | 电源 | 新建：pmset 开关+电源域（从弹窗电源 tab 迁入）、电源助手管理（从快捷操作迁入）、**电源监控可见开关（新增）**、唤醒历史保留与恢复（原仪表盘>电源的恢复链接迁入） |
| 系统 | 通用 | 登录时启动+自动更新（原关于）、外观模式组（原外观第一组）、语言（原语言分区）、iCloud 同步（原独立分区，保持 entitled 条件显示） |
| 系统 | 关于 | 只剩版本信息与链接 |

- 「概览」「外观」「iCloud 同步」「语言」「日期与时间」「快捷操作」「通知」分区消失（内容全部有新家，一项不丢）。
- 「仪表盘」从设置窗口移出，成为独立窗口（见 R4）。
- 默认打开分区 = 侧边栏第一项（菜单栏）；原有 deep-link（状态卡点击、概览检查行跳转等）全部映射到新分区。

### R2. 隐式行为修复
- `powerMonitoringEnabled`：新增可见开关（电源分区），弹窗/仪表盘 onAppear 不再隐式写 true——改为首次进入时提示一次或直接依赖开关默认值（实现取其一并记录）；已开启用户保持开启。
- 弹窗电源 tab 的「电源配置卡」替换为状态摘要 + 「在设置中配置」跳转（系统级开关单一归属设置窗口）。

### R3. 操作中心（画板 D）
- 磁贴点击不再直接执行；行/磁贴提供显式「运行」按钮与固定图钉（消除设置页误触执行）。
- 分来源展示：内置 / 快捷指令 / 触控板原生（读子任务 2 的 ActionCatalog；若目录含 trackpad surface 动作则显示）。
- 每个动作显示「被引用」：已固定（面板）/ 被哪些手势规则引用（扫描 trackpadGestureSettings 的 quickAction 引用）。
- 电源助手分组迁出到「电源」分区。

### R4. 仪表盘独立窗口
- DashboardView 整体平移到独立 NSWindow（标题「仪表盘」，尺寸沿用现设置窗口内容区）；弹窗状态卡点击、原设置入口 deep-link 改为打开该窗口。
- 仪表盘>电源里的「恢复唤醒历史」链接迁到设置>电源（与清除动作同处，撤销与操作同一归属）。

### R5. 弹窗「操作」页重组（画板 E）
- 顶部搜索框（按标题过滤全部来源）+「编辑」入口（跳操作中心）。
- 已固定网格保留；其余动作按分组折叠列表展示（内置按类别分组、快捷指令独立组默认折叠）；不可用动作行内显示原因徽标。
- 底栏加「管理操作…」（跳操作中心）。

### R6. 本地化与迁移
- 全部新分区名、分组名、迁移后的说明文案 en/zh-Hans 双语；LocalizationCoverageTests 通过。
- 用户已有设置值零迁移成本（存储键不变，仅 UI 归属变化）；`SettingsPane` 枚举 rawValue 若被持久化/深链引用，提供旧值映射。

## Acceptance Criteria

- [ ] 盘点表中的每一个设置项在新 IA 里可达且只有一个归属（对照 research/ui-inventory.md 第二节逐项核对，附核对清单于任务 notes）。
- [ ] 设置页不存在「点击即执行」的动作入口。
- [ ] powerMonitoringEnabled 有可见开关；关闭后 pmset/top 后台采样停止（代码路径核验）。
- [ ] 弹窗四 tab、右键菜单、深链全部指向新归属，无死链接；设置窗口重开不崩（pane 重置问题属子任务 4，不在此修）。
- [ ] `swift build`、`swift test`、LocalizationCoverageTests 全绿。
- [ ] 与画板 A/B/D/E 的结构一致（分组、分区名、操作中心列结构、弹窗操作页区块）。

## 范围外

- 导航状态/深链机制重构（子任务 4）。
- 触控板规则编辑器改为弹层（画板 C 的交互形态，工作量大，留后续任务；本次仅保持内联编辑器并入新分区）。
- Dashboard 图表内容与采样逻辑。
