# 日历个性化：日期距离与月度工作日

## 背景

用户需求（2026-08-28）：月历要更多个性化——①选中/悬浮某一天时显示「距今多少天、换算多少周」；②展示每个月的工作日统计等。工作日口径用户已拍板：**含中国法定节假日与调休**。

## Requirements

### R1. 日期距离展示
- 悬浮月历任一日期格：在月历与日期详情卡之间的固定信息条（不遮挡格子）显示该日期的距离描述；移开即恢复（无悬浮时该条隐藏或显示选中日信息）。
- 选中日期：日期详情卡内新增一行「距今」描述（常驻）。
- 距离文案规则：今天→「今天」；±1 天→「昨天/明天」；其余「N 天前 / N 天后」；N ≥ 7 时追加周换算「（X 周）」或「（X 周 Y 天）」（整除时省略天）。
- 若该日期命中节假日/调休数据：追加标签（如「国庆节 · 假期」「调休上班」）。

### R2. 月度工作日统计
- 月历网格下方一行紧凑统计：非当月视图「N 个工作日 · M 个休息日」；当月视图追加进度「已过 A · 剩 B」（含今天算未过）。
- 工作日判定：周一至周五，**减去**法定节假日放假日，**加上**调休补班的周末（数据见下）。
- 数据未覆盖的年份：回退为纯周一至五口径，统计行加细字提示「按周一至五估算」。

### R3. 法定节假日与调休数据（内置，权威来源已核）
数据结构按年组织：`holidays`（放假日区间+名称）与 `makeupWorkdays`（调休上班的周末日+所属节日）。

- 春节：2/15–2/23 放假；2/14（周六）、2/28（周六）上班
- 清明节：4/4–4/6 放假，不调休
- 劳动节：5/1–5/5 放假；5/9（周六）上班

### R4. 个性化开关（设置 → 日历分区）
- 「悬浮显示日期距离」开关（默认开）。
- 「月度工作日统计」开关（默认开）。
- 「工作日口径」选择：含法定节假日调休（默认）/ 仅周一至五。
- 持久化进 AppSettings（新字段 + SettingsStore 键 + 默认值）。
- 与现有日历字段一致（portable）：三个字段进 iCloud portable 集，与 `calendarWeekStartDay` / `showsLunarCalendar` / `allDayEventDatePolicy` 同规格——同属显示偏好，跨 Mac 漫游符合用户预期；冲突合并方向沿用既有机制（按 `portableModificationDates` 后写覆盖，无逐字段特判）。
  - 订正记录（2026-08-28，team-lead 拍板）：原文写作「不进 iCloud portable 集，与现有日历字段同规格」，但现有日历字段实际全部 portable，两句自相矛盾；以「与现有日历字段一致」为准。
