# 规则编辑器高级收纳

## 背景
用户反馈（2026-08-28）：「现在界面有点复杂 部分可以收纳到高级设置」。规则编辑弹窗一屏塞了 15+ 字段，高频与低频混排。

## Requirements
- 弹窗保持三段式，但每段只常显高频字段：
  - 触发手势段常显：手势类型、手指数、族关键参数（所选滑动指/轴向、方向、边缘、区域、组合模式等「定义这个手势是什么」的参数）。
  - 动作段常显：操作类型与动作选择、可用性提示。
  - 生效范围段常显：应用范围。
- 低频字段收进各段尾部的「高级」DisclosureGroup（默认收起）：所需修饰键、全部阈值滑块（锚定按住时间/最长持续时间/移动容差等）、轻点间距、绘制激活方式等调参项；范围段的触摸板设备、指针窗口激活、备注。
- 打开编辑器时，若某段高级字段存在**非默认值**，该段折叠自动展开（不许把用户已配置的东西藏起来）。
- 「高级」标题带一行小字说明（如「阈值与调参，默认值适合大多数情况」）；en/zh 双语（先查 "Advanced" 键是否已存在避免重复）。
- 纯排布重构：字段控件、绑定、normalize 逻辑零改动；草稿语义不变。

## Acceptance Criteria
- [ ] build/test 全绿（TrackpadRuleEditorSheetTests 断言零改动——若测试引用布局结构需只调取值路径）；verify-localizations 通过。
- [ ] 非默认检测单测：构造含非默认阈值/备注的规则 → 对应段展开标志为真；全默认 → 收起。
- [ ] 新建规则（全默认草稿）打开时高级区全部收起。

## 追加 R0（2026-08-28 用户第二条消息）：触控板分区顶部 tabs

分区现状为长滚动堆叠（运行状态/点击抑制/实时预览/反馈与边缘控制/手势规则/规则集）。改为顶部 tabs 分类（视觉复用仪表盘分区的横向 tab 样式）：

| Tab | 内容 |
|---|---|
| 手势规则（默认） | 规则表格 + 添加规则 + 规则集（导入/导出/重置预设） |
| 反馈与参数 | 反馈与边缘控制组（触觉反馈/反馈浮层/边缘宽度/灵敏度） |
| 运行与诊断 | 运行状态（总开关/设备/重试）+ 点击抑制及其状态行 + 实时触控预览 + 最近识别 |

- 总开关「启用触摸板手势」若移入诊断 tab 会藏太深——把总开关 Toggle 保留在分区标题行右侧常显（各 tab 都可见），诊断 tab 内保留完整状态卡。
- tab 选择为分区内 @State（不进 router/持久化——轻量导航，窗口会话内记忆即可）。
- 30Hz 实时预览的 VisibilityGate 门控随 tab 切换联动：预览不可见（非诊断 tab）时停止发布（onAppear/onDisappear 已有机制，确认 tab 切换真的触发）。
- 双语 tab 标题。

验收补充：
- [ ] 三个 tab 内容完整覆盖原分区全部元素，一项不丢（对照现状清点）。
- [ ] 非诊断 tab 下触控预览订阅停止（读代码路径核验 retain/release 配对）。
