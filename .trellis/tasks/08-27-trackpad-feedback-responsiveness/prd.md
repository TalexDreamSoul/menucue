# 触控板反馈浮层移除与灵敏度修复

## 背景

用户实机反馈（2026-08-28，两条消息）：①「音量 34%。」反馈浮层不要（截图为跟随鼠标的深色 HUD 面板）；②手势不灵敏；③新规则表格的触发器徽标文案「很奇怪」（截图：边缘规则显示「2 指 · 向左」、tipTap 显示「第 1 指 · 正常」）。

## Requirements

### R1. 反馈浮层改为固定屏底样式（用户 2026-08-28 第二条消息修订：不是删除，是不要跟随鼠标）
- HUD 保留但重定位：**固定在屏幕底部居中**（参照系统音量 bezel 的位置感：visibleFrame 底边上方留边距，自动避开 Dock），不再跟随鼠标移动。
- **多屏适配**：每次展示时显示在**鼠标指针所在的那块屏**（NSScreen 按 NSEvent.mouseLocation 命中，找不到回退主屏）；用该屏自己的 visibleFrame 计算位置；面板 transient（~1.6s 自动消失），每次展示重算位置，屏幕参数变化天然自愈。
- 「反馈浮层」设置开关与字段**保留不动**（用户可关）；触觉反馈不动。
- 文案微修：去掉「音量 34%。」结尾的句号（en/zh 同步检查该键）。
- 视觉保持现有胶囊风格即可，不做新视觉语言。

### R2. tipTap 按住连发（声明的行为变更）
- 现状：一次会话只发射一次（didEmitDiscrete disarm），按住锚指连点第二下无效，必须全部抬手重来——这是「不灵敏」的主因。
- 目标：锚指保持按住期间，移动指每完成一次「抬起→点按→抬起」发射一次；相邻发射间防抖冷却 ~0.12s；会话内其他约束（位移容差、重触半径、时长阈值）不变。
- 原「exactly once per session」契约的对应测试断言按新语义更新（这是产品负责人明确要求的行为变更，需在 notes.md 记录哪些断言改了、旧→新语义）；其他手势族的一次性语义不受影响。

### R3. 边缘连续调节响应提升
- 冷却 0.055s → 0.035s；单帧步数上限 3 → 4；最小步进 0.004 维持。
- 音量/亮度连续步长系数 0.025 → 0.035（更跟手），钳制上限 0.2 不变。
- 全局「灵敏度」滑块语义不变（用户已可调）；只动默认体感。

### R4. 触发器徽标文案修正（表格）
- edgeContinuous 第二枚徽标：显示边缘名「N 指 · 左边缘/右边缘/上边缘/下边缘」，**不是**方向词「向左/向右」。
- tipTap 第二枚徽标：改为可读表述（如「按住另一指 · 第 1 指点按」風格，用现有本地化词汇拼装）；「正常」这类默认参数值不再显示——所有族的徽标只在参数非默认时展示该参数。
- triggerBadges 单测随新文案更新断言（保持"兄弟规则徽标必须可区分"与"全族两枚非空"两条不变量）。

## Acceptance Criteria

- [ ] `swift build`、`swift test`、`--filter Trackpad`、verify-localizations 全绿。
- [ ] R1：HUD 定位逻辑不引用鼠标位置作为面板原点（只用于选屏）；位置计算基于目标屏 visibleFrame（可抽纯函数配单测：给定屏 frame/visibleFrame → 面板 origin，覆盖 Dock 在底/左/右三种 visibleFrame 形态与双屏坐标系）；文案无结尾句号。
- [ ] R2 新语义测试：按住锚指连点 3 次 → 恰好 3 次动作、间隔小于冷却的第 2 次点按被防抖；全部抬手重按仍正常。
- [ ] 徽标：四条预设的第二枚分别为「第 1 指点按」类表述×2、「2 指 · 左边缘」「2 指 · 右边缘」（准确文案实现定，但不得再出现方向词/「正常」）。
- [ ] 新文案 en/zh-Hans 双语。

## 范围外

- 识别阈值（0.18s hold 等）与其他族的调整。
